# smaragd-sync-e2e

End-to-end tests for Smaragd's sync feature: the real desktop client
([smaragd](https://github.com/smaragd-editor/smaragd)) against the real sync server
([smaragd-sync](https://github.com/smaragd-editor/smaragd-sync)). Kept in its own
repo because it's the only place that depends on both.

```sh
cargo test
```
